Job Application Tracker

A Java console application that allows users to add, view, remove, and track job applications. The application also provides statistics based on application status.
Features

    Add job applications
    View all applications
    Remove applications
    Track application status
    Search applications by company
    Search applications by position
    Filter applications by status
    Add notes to applications
    Calculate application statistics
    Calculate interview and offer rates
    Input validation

Technologies

    Java
    Object-Oriented Programming
    ArrayList
    Enums
    Java Collections
